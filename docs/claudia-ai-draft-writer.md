## Claudia AI draft writer (review-only)

`scripts/claudia_draft_writer.py` calls the OpenAI Chat Completions API using the model configured by `CLAUDIA_WRITER_MODEL`. It only drafts leads that have source excerpts from at least two distinct domains, and skips a lead if a draft already exists. Source links are appended from the evidence records, not generated by the model.


Drafts are saved as `needs_review` and `unverified`; they are never published. Sensitive-topic keywords are flagged in editor notes. The scheduled workflow runs the writer only after discovery/intake and only when credentials are present; otherwise the script prints a safe skip message. Required secrets: `OPENAI_API_KEY`, `CLAUDIA_WRITER_MODEL`, and Supabase service-role credentials. Optional: `OPENAI_API_URL` for compatible gateways.
